# Octopus 验证桥

用于持久配对 Octopus，并在通过 Cloudflare 验证的真实浏览器标签页中执行站点同步或签到请求的 Manifest V3 扩展。

## 加载扩展

1. 打开浏览器的扩展管理页面。
2. 启用开发者模式。
3. 选择”加载已解压的扩展程序”，并加载本目录。

## 首次连接：手动确认可信地址

网页链接不能建立首次信任。首次连接或删除全部配对后，请先在可信的 Octopus 管理端创建配对，点击扩展图标并展开“添加配对”，核对 Octopus 地址、输入配对令牌，再点击“验证并信任此地址”。配对后扩展可以通过浏览器执行该服务器下发的站点任务，请勿保存不可信服务器的地址或令牌。

已安装旧版扩展的用户需要在扩展管理页面重新加载本目录。既有配对继续有效；如果曾保存来源不明的配对，请先删除并在可信管理端撤销相应令牌。

## 已信任地址的一键浏览器同步

1. 在 Octopus 管理端的站点账号卡片中点击”浏览器同步”按钮（地球图标）。
2. Octopus 会自动创建配对和验证任务，并在浏览器新标签页中打开目标站点。
3. 扩展只接受已有配对中相同 origin（协议、主机、端口）的自动配对信息并接管任务。未知地址必须先手动确认。如果目标站点需要登录或 Cloudflare 验证，请在打开的标签页中完成。
4. 验证通过后，扩展自动通过浏览器执行同步请求，完成后在扩展弹窗中查看状态。

配对信息通过 URL fragment 传递，扩展读取后会从地址栏移除。不要分享含配对令牌的链接。

## 添加或重新连接配对

首次连接以及一键同步不可用时，请手动添加配对：

1. 在 Octopus 中为指定站点账号创建配对，获取一次性显示的配对令牌。
2. 点击扩展图标，展开”添加配对”，输入 Octopus 地址和配对令牌。
3. 配对保存后会显示设备、站点和账号。扩展重启后不需要再次输入。

## 使用流程

1. Octopus 遇到 Cloudflare 后会为已配对账号创建验证任务。
2. 扩展后台自动领取任务，并在普通浏览器窗口中创建或复用一个不激活的目标站点标签页。
3. 扩展不会自动切换窗口或抢占焦点。如果 Cloudflare 要求人工确认，扩展图标会显示橙色 `!`；点击扩展中的”打开验证页面”后完成验证，扩展会自动继续。
4. 扩展在目标标签页中执行 Octopus 请求，直到同步或签到成功/失败。

扩展弹窗关闭后，后台 Service Worker 仍会自动处理新任务。后台验证标签页会被后续任务复用，不会为每次签到或同步重复弹出窗口。扩展需要访问配对站点，才能在目标页面主世界中使用浏览器自身的 Cookie、TLS 指纹和网络环境；请求仍被限制在任务目标 origin，Octopus 不会接收浏览器 Cookie。

弹窗中的领取、打开、执行和释放按钮作为故障恢复控制保留，正常情况下不需要手动操作。

如果浏览器重启时任务领取凭据已经过期或被服务端释放，扩展会自动清理旧状态并允许重新领取；如果服务端已经接受”验证完成”但响应在途中丢失，扩展会恢复正在执行的任务。

配对令牌保存在扩展本地存储中，只会发送到对应 Octopus 实例。扩展数据丢失时，请在 Octopus 管理端轮换该配对令牌，再用新令牌重新添加；旧令牌会立即失效。
